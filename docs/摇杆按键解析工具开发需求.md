# 摇杆按键解析工具开发需求

## 1. 项目概述

本项目是一个基于 Python + ttkbootstrap 开发的摇杆按键串口解析工具，用于通过串口通信接收和解析摇杆、按键、ADC和LED设备的数据，并提供可视化界面和控制功能。

## 2. 功能模块

### 2.1 连接串口

#### 需求
- 自动扫描并显示可用串口列表
- 支持多种波特率选择（9600, 38400, 57600, 115200）
- 实时显示连接状态
- 提供手动刷新串口列表功能
- 支持串口参数配置（数据位、停止位、校验位）

#### 页面内容
- 串口选择下拉框
- 波特率选择下拉框
- 连接/断开按钮
- 刷新串口列表按钮
- 连接状态显示

### 2.2 数据解析

#### 需求
- 实时解析并显示24个按键状态
- 实时解析并显示14个ADC通道数据（带进度条可视化）
- 实时解析并显示20个LED状态
- 显示原始数据帧
- 数据有效性验证

#### 解析规格

**数据帧格式**：
- 帧头：`0xAA`
- 帧尾：`0xBF`
- 帧长度：24字节
- 校验和：异或校验（从帧头到校验和前一字节的异或结果）

**数据帧结构**：
| 偏移 | 长度 | 描述 |
|------|------|------|
| 0    | 1    | 帧头 (0xAA) |
| 1    | 1    | 索引值 |
| 2-4  | 3    | 按键状态（24位，每8位一个字节） |
| 5-18 | 14   | ADC数据（14个通道，每个通道1字节） |
| 19-21| 3    | LED状态（20位，每8位一个字节） |
| 22   | 1    | 校验和 |
| 23   | 1    | 帧尾 (0xBF) |

**解析逻辑**：
1. 从串口读取数据
2. 从后往前搜索有效帧（确保只处理最新的一帧）
3. 验证帧头、帧尾和校验和
4. 解析按键、ADC和LED数据
5. 更新UI显示

#### 页面内容
- 按键状态显示区域（24个按键，带状态指示）
- ADC数据显示区域（14个通道，带进度条）
- LED状态显示区域（20个LED，带状态指示）
- 原始数据帧显示区域
- 数据有效性显示

### 2.3 LED灯测试

#### 需求
- 20个LED灯独立控制
- 可视化开关状态
- 实时显示发送的指令

#### 发码规则

**LED控制指令格式**：`CC XX YY BF`
- `CC`：指令前缀
- `XX`：LED索引（0-19）
- `YY`：LED状态（00=关闭，01=打开）
- `BF`：指令后缀

**发送逻辑**：
1. 用户点击LED开关
2. 生成对应的控制指令
3. 通过串口发送指令
4. 更新UI显示发送的指令

#### 页面内容
- 20个LED控制开关（带状态指示）
- 发送指令显示区域
- 批量控制功能（全亮/全灭）

### 2.4 设备校准

#### 需求
- 通道使能控制
- 多种校准模式（自动/手动）
- 支持中心点和量程校准
- 支持摇杆、电位器、按键设备
- 自动生成校准指令

#### 发码规则

**校准指令格式**：`81 10 XX XX XX XX XX 00 YY`
- `81 10`：指令前缀
- `XX XX XX XX XX`：校准参数
- `00`：保留位
- `YY`：校验和

**校准模式**：
1. 自动校准：设备自动完成校准过程
2. 手动校准：用户手动输入校准参数

**校准参数**：
- 中心点校准：设置ADC通道的中心点值
- 量程校准：设置ADC通道的最小和最大值

#### 页面内容
- 通道选择（14个ADC通道）
- 校准模式选择（自动/手动）
- 设备类型选择（摇杆/电位器/按键）
- 校准参数输入区域
- 校准指令显示区域
- 开始校准按钮

### 2.5 自定义名称

#### 需求
- 支持为按键、ADC通道、LED灯自定义名称
- 配置自动保存
- 配置加载功能

#### 页面内容
- 按键名称编辑区域（24个按键）
- ADC通道名称编辑区域（14个通道）
- LED名称编辑区域（20个LED）
- 保存配置按钮
- 加载默认配置按钮

## 3. 技术实现

### 3.1 技术栈
- **语言**：Python 3.x
- **GUI框架**：ttkbootstrap
- **串口库**：pyserial
- **数据处理**：内置数据结构
- **配置管理**：JSON文件

### 3.2 核心功能实现

#### 串口通信
- 使用pyserial库实现串口的打开、关闭、读写操作
- 采用多线程处理串口数据读取，避免阻塞UI

#### 数据解析
- 实现帧解析算法，处理串口接收的数据
- 使用队列存储串口数据，确保数据不丢失

#### LED控制
- 根据用户操作生成控制指令
- 通过串口发送指令到设备

#### 设备校准
- 根据校准模式生成相应的校准指令
- 处理校准过程中的数据反馈

#### 配置管理
- 使用JSON文件存储配置信息
- 实现配置的加载和保存功能

## 4. 界面设计

### 4.1 整体布局
- 采用标签页式布局，每个功能模块一个标签页
- 响应式设计，适配不同屏幕尺寸
- 支持主题切换（明/暗）

### 4.2 页面布局

#### 连接串口页面
- 顶部：串口配置区域
- 中部：连接控制区域
- 底部：状态显示区域

#### 数据解析页面
- 顶部：按键状态显示（4行6列网格）
- 中部：ADC数据显示（2行7列网格，带进度条）
- 底部：LED状态显示（4行5列网格）和原始数据显示

#### LED测试页面
- 顶部：LED控制区域（4行5列网格，带开关）
- 底部：指令显示区域和批量控制按钮

#### 设备校准页面
- 顶部：通道和模式选择区域
- 中部：校准参数输入区域
- 底部：校准指令显示和控制按钮

#### 自定义名称页面
- 顶部：按键名称编辑区域
- 中部：ADC通道名称编辑区域
- 底部：LED名称编辑区域和配置按钮

## 7. 注意事项

1. 确保设备支持相同的通信协议
2. 连接设备前请确认串口参数设置正确
3. 操作过程中请勿关闭应用或断开设备连接
4. 设备校准前请仔细阅读校准说明
5. 程序应具备良好的错误处理能力，避免因异常情况崩溃
6. 应采用多线程处理串口数据，确保UI响应流畅
